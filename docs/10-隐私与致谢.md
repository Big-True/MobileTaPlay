# 隐私与致谢

## 隐私说明

MobileTaPlay 是纯第三方 **魔塔（h5mota）客户端**，以「尽量少收集、不上传」为原则：

| 数据 | 用途 | 是否离开设备 |
|---|---|---|
| 网络请求（塔列表 / 详情 / 游戏资源） | 在线浏览与游玩 h5mota 内容 | 仅访问 `h5mota.com` 及其静态资源 |
| 手柄映射、偏好设置 | 本机操作体验 | 否，存于应用私有存储 |
| 最近游玩 / 星标 / 缓存 | 本地列表与离线游玩 | 否，存于应用私有目录 |
| 账号 / 登录 / 统计 SDK | — | **不使用**（无账号、无埋点、无崩溃上报） |

补充说明：

- 不请求通讯录、短信、位置等无关权限；不需要账号体系。
- 游戏内容与站点 Cookie/存储策略以 [h5mota.com](https://h5mota.com) 及各塔作者条款为准；本客户端不重新分发游戏资源。
- 缓存与设置可清除：应用内「删除缓存」、系统设置清除应用数据即可。
- 本应用不提供未成年人定向服务以外的额外数据处理；不售卖任何数据。

## 第三方声明

- MobileTaPlay 为社区第三方客户端，与 h5mota.com 官方、mota-js 作者 **无隶属关系**，亦不代表官方立场。
